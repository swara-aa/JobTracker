# Security Policy

## Secrets

Store API keys and SMTP credentials in environment variables. Never commit them, paste them into issues, or add them to screenshots.

## Reporting Issues

For a potential security issue, do not open a public issue containing sensitive details. Contact the repository owner privately with a minimal reproduction and affected version.

## Supported Development

This project is currently under active development. Keep dependencies updated and review public-source integrations before enabling them in production.
